## About

Bored of staring at code all day?

Meet  Daisy the Mew: a tiny cat that wanders around your desktop, takes cozy nap,Reacts to nearby cursor movement with subtle head tilts,and lets you pick her up for a quick cuddle.

She's not here to boost your productivity.

She's here to make your desktop a little more alive.

## Features

- Walks and runs around your desktop

- Sleeps when she's tired

- Pick her up and drag her anywhere

- Curiously watches your mouse movements

- Falls with cute bouncy physics when dropped

- Loves sitting on the bottom edge of your screen

## Quick Start

Clone the repository:

```bash
git clone https://github.com/TanvirTian/daisy-the-mew.git
cd daisy-the-mew
```

Install the dependencies:

```bash
go mod tidy
```

Run Daisy:

```bash
go run .

```
